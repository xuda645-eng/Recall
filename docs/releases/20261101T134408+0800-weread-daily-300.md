  server limiter, remaining-budget endpoint and client response validation.

  attempts are retained; failed model attempts count. UTC midnight corresponds
  to 08:00 in China. Raising the ceiling does not reset usage or start AI calls.

  cache reuse at the daily ceiling, UTC rollover and client rejection checks.
  Synthetic mobile API fixtures now return the full 300 to exercise client
  compatibility rather than silently testing only the old 100 range.
