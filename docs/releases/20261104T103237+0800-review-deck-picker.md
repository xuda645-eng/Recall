## Changes

- Remove the permanent homepage deck select and scope-dependent recommendation count. Retain the illustration variants and replace the hero with a calm invitation to study one deck.
- List every unarchived deck, including empty decks, with collapsible hierarchy and separate selection controls. Show currently due old cards, never-rated new cards and unarchived total cards. Parent scope includes descendants; mixed scope counts cards once rather than summing parent and child rows.
- Preselect the last confirmed device-local preference. Selection only changes the preview; cancellation does not persist it. The actual study plan determines the old/new allocation and batch size, not prototype sample numbers.
- Confirmation starts review or new-card learning. If all active content is not yet due, offer explicitly ungraded browsing. Empty or newly archived selections cannot start. Invalid remembered IDs fall back to an individual active deck, not mixed study.
- Independent sheet-body scroll, fixed 48px confirmation, four safe-area insets, mobile bottom-sheet layout and desktop centered layout. Add summaries and visible-only controls to the keyboard focus trap.
- Capture the originating control before applying inert on WebKit. Returning from reading restores the homepage start action rather than the now-unmounted confirmation control.
- Keep archive controls, handlers, three-second undo, stored card bodies, ratings, scheduling algorithm and cloud protocol unchanged.
