## Changes And Rationale

The first online import includes AI questions, rather than deferring them.
The PWA reads real WeRead notebooks with highlight counts and cursor pagination,
fetches only selected books, and generates one editable question per highlight.
Exact original highlights remain answers; optional auxiliary summaries are
visibly non-source. Local JSON and clearly separated original demos remain.
Imports reuse source identity, unchanged skipping and explicit change selections;
no book replacement, implicit deletion, review/history/archive reset or automatic
import. Existing and manual questions are not automatically regenerated.

New server routes are authenticated, same-origin-only POSTs. All four supplied
connection values are production encrypted secrets, never frontend variables,
Git content or logs. Gateway and Ark destinations are fixed. Requests are serial
in the UI, 20 highlights/action, 6000 characters/highlight, 384 output tokens,
100 model attempts per UTC day across the space including failures, 120/hour
AI requests including cache hits and 120/hour WeRead reads. Seven-day content
cache is separate from cards. AI JSON and lengths are checked; users must still
verify semantic answerability, since schema checks cannot prove it.

`20261031_weread_ai.sql` adds `import_request_limits` and
`import_question_cache`; no existing card/sync schema or data is changed.
WebKit's native select measured only 23px despite shared min-height; scoped
appearance/height styling fixes it to 48px without touching concurrent appearance
work. Primary device baseline remains 393 x 852 CSS pixels, DPR 3.
